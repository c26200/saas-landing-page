# Nexus AI — Rediseño 2026

## Spec (común a las tres direcciones)

**Qué es.** Landing de un SaaS de IA ficticio: automatiza procesamiento de datos,
integraciones y analítica.

**Audiencia.** Desarrolladores y equipos que evalúan herramientas; alguien que decide en
menos de un minuto si sigue leyendo.

**Mensaje central.** Automatiza tu flujo de trabajo a la velocidad de la luz — sin perder
control ni seguridad.

**Tono.** Seguro y concreto. No hype vacío.

**Formato.** Primera pantalla a 1440×900 (hero + franja de features); las tres comparten
contenido.

**Contenido real.** Badge "Nexus AI 2.0 is now live"; H1 "Automate your workflow at light
speed."; subtítulo "Stop wasting time on manual tasks. Let Nexus handle your data
processing, integrations, and analytics with the power of advanced AI."; CTAs "Start
Automating" / "View Demo". Features: Real-time Analytics, Smart AI Logic, Enterprise
Security, Global Edge Network, Team Collaboration. Planes: Starter $0, Pro $29 (popular),
Enterprise $99.

**Restricciones.** Sin gradientes morados genéricos, sin glassmorphism, sin emojis como
iconos. Cuerpo ≥14 px, etiquetas ≥12 px, contraste ≥4.5:1.

## Candidatos

### 1 · Best designer — Paula Scher (Pentagram)
- **Lógica.** Tipografía como arquitectura, color primario saturado, composición diagonal,
  energía cívica y directa.
- **Qué se toma.** Titular gigante, negro + verde ácido, una línea diagonal que corta el
  encuadre, CTA sólido.
- **Esqueleto.** Manifiesto a sangre + franja de features numerada.
- **Audacia.** El H1 ocupa media pantalla y se sale del margen.
- **Form.** Un producto de velocidad debe sentirse rápido antes de leerse.

### 2 · Best designer — Collins
- **Lógica.** Branding cinematográfico: una idea por pantalla, tipografía enorme, contraste.
- **Qué se toma.** Titular de cartel, negro cálido, un acento, el producto como escena.
- **Esqueleto.** Portada + estante de features + bloque de precio.
- **Audacia.** Una palabra domina la portada.
- **Form.** La automatización se recuerda por una escena, no por una lista.

### 3 · Referencia real — Linear (linear.app)
- **Lógica.** Landing de producto oscura y precisa: nav mínima, titular sobrio, UI real.
- **Qué se toma.** Fondo tinta, acento eléctrico, mock de producto, densidad.
- **Esqueleto.** Nav + hero centrado + mock.
- **Audacia.** El producto real es el protagonista.
- **Form.** Herramienta para developers: mostrar la herramienta.

### 4 · Referencia real — Stripe (stripe.com)
- **Lógica.** Landing developer de referencia: claro, malla de gradiente, densidad, prueba.
- **Qué se toma.** Fondo claro, gradiente mesh, bloque de código/producto, jerarquía.
- **Esqueleto.** Nav + hero a dos columnas + features en grid.
- **Audacia.** Claridad y confianza técnica.
- **Form.** Para developers, el detalle técnico es la prueba.

### 5 · Ruleta — web #4 Friendly Candy (Duolingo)
- **Lógica.** Duolingo: verde `#58CC02`, amarillo `#FFC800`, azul `#1CB0F6`, botones
  convexos con sombra dura inferior, esquinas muy redondeadas.
- **Qué se toma.** Botón 3D que se hunde, tarjetas redondeadas, mascota geométrica.
- **Esqueleto.** Hero centrado + botón grande + features en tarjetas redondeadas.
- **Audacia.** Una IA que se siente amable, no intimidante.
- **Form.** Automatizar da miedo; la interfaz puede quitarle ese miedo.

### 6 · Ruleta — east #12 POPEYE / revista densa
- **Lógica.** POPEYE y BRUTUS: papel, retícula densa, titulares grandes con subrayado,
  anotaciones manuscritas rojas y azules, celdas de datos.
- **Qué se toma.** Densidad editorial, numeración, notas al margen, cuadros de color.
- **Esqueleto.** Portada de revista con sumario numerado y ficha técnica.
- **Audacia.** La landing se lee como el número de una revista dedicada al producto.
- **Form.** Un lanzamiento es un número: portada, sumario, reportaje.
